# Projeto BI — Mercado de Games

## Sobre o projeto

Projeto acadêmico desenvolvido para a disciplina de Inteligência de Negócios nas Organizações — Business Intelligence.

O projeto realiza uma análise exploratória de dados do mercado de videogames utilizando Python e ferramentas de Business Intelligence.

## Objetivo

Analisar dados históricos do mercado de videogames, identificando padrões relacionados a:

- vendas;
- consoles;
- gêneros;
- publishers;
- regiões;
- evolução temporal;
- avaliações;
- mercado brasileiro.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Streamlit

## Dashboard

O projeto possui um dashboard interativo desenvolvido com Streamlit para apresentar os principais resultados da análise.

## Estrutura do projeto

- `dashboard.py` — aplicação principal do dashboard.
- `01_exploracao.py` — análise exploratória inicial.
- `data/` — bases de dados utilizadas.
- `requirements.txt` — bibliotecas necessárias para executar o projeto.
- `README.md` — documentação inicial do projeto.

## Principais análises

O projeto apresenta análises sobre:

- vendas por console;
- vendas por gênero;
- vendas por publisher;
- vendas por região;
- evolução temporal;
- jogos com maiores vendas;
- avaliação dos dados;
- mercado brasileiro;
- limitações das bases utilizadas.

## Observações

Os resultados representam os dados disponíveis nas bases utilizadas no projeto. Valores ausentes e diferenças de cobertura temporal devem ser considerados durante a interpretação dos resultados.
